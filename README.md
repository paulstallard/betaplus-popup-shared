# BetaPlus Pop-up: Shared Repo

The shared practice repo for the BetaPlus Git and GitHub pop-up on 26 November 2026.

Everyone adds a file about themselves to the `people` folder. Nobody pushes straight to `main`.
Every change goes through a branch and a pull request:

1. Clone this repo and create a branch called `add-<username>`.
2. Create `people/<username>.txt` with a line or two about yourself.
3. Commit it, push the branch and open a pull request.
4. Review a neighbour's pull request and leave a comment.
5. Merge your own pull request, then pull `main` to see everyone else's files.

`people/example.txt` shows what a file might look like.
